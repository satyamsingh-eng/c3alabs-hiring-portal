2. Role Criteria & Evaluation Matrix

Every candidate was evaluated against 4 core pillars defined in the SARVAX Job Specifications:
  • 1. Open to Work Verification: Explicit availability signal to guarantee candidate responsiveness and retention.
  • 2. Technical Configuration: Direct proficiency in REST APIs, Webhooks, JSON schemas, Python/JS, and LLM prompt design.
  • 3. System Integration: Hands-on experience debugging OAuth, API endpoints, and business software (CRMs, databases).
  • 4. Ownership: End-to-end commitment from initial discovery call through pilot launch, client onboarding, and product feedback loop.
